# Simulador de Gestão de Desempenho

Ambiente exclusivo do Simulador de Gestão de Desempenho da EE Caetano de Campos.

Este repositório é independente do Simulador de RH.

## Publicação

O projeto é publicado como site estático no GitHub Pages.

## Estrutura

- `index.html`
- `styles.css`
- `app.js`
- `dados/cenarios.json`
- `dados/participantes.json`

Os resultados são enviados pelo próprio simulador ao Google Apps Script configurado no `app.js`.
